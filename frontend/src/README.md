# Tshwane Bus Service App
A comprehensive application for the Tshwane bus service with real-time tracking, user profiles, notifications, and community features.
## Features
- User authentication and profiles
- Real-time route tracking on Google Maps
- Route-based notifications
- Community forum with real-time chat
- Stripe payment integration for card top-ups
- Responsive design for mobile and desktop
